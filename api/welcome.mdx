The Meridian API lets third-party apps access a Meridian user's account through **OAuth 2.0** (authorization code flow).

Register applications, copy credentials, and build consent URLs in the [developer portal](https://developer.meridian.surf).

<Note>
  This is the Meridian OAuth API. It is not the [Discord Developer Portal](https://discord.com/developers/applications), which is for Discord bot tokens and Discord application settings.
</Note>

## What you can build

- Sign users in with Meridian and read their profile
- List bots, flows, guilds, and cowork access the user grants
- Stay signed in with refresh tokens (`offline_access`)
