The **Set Voice Channel Status** block lives in the **Voice** palette category. Set the status message shown on a voice channel.

## What it does

Set the status message shown on a voice channel.

## Configuration

Open the block in the builder sidebar to configure these fields.

<ParamField path="channel_id" type="channel" required>
  Voice channel whose status text updates.
</ParamField>

<ParamField path="status" type="string">
  Short status message shown on the channel (for example, "Listening to music…").
</ParamField>
