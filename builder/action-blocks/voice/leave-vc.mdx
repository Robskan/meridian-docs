The **Leave Voice Channel** block lives in the **Voice** palette category. Disconnect the bot from voice.

## What it does

Disconnect the bot from voice.







## Configuration

Open the block in the builder sidebar to configure these fields.

<ParamField path="guild_id" type="guild">
  Server to disconnect from. Defaults to the current server.
</ParamField>
