The **Move a member from VC** block lives in the **Voice** palette category. Move a user between voice channels.

## What it does

Move a user between voice channels.



## Configuration

Open the block in the builder sidebar to configure these fields.

### `user_id`

**Type:** `user`. Required.

Member to move.

### `target_channel_id`

**Type:** `channel`. Required.

Destination voice channel.
