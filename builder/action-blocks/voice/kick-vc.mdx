The **Kick a member from VC** block lives in the **Voice** palette category. Disconnect a user from voice.

## What it does

Disconnect a user from voice.

## Configuration

Open the block in the builder sidebar to configure these fields.

### `user_id`

**Type:** `user`. Required.

Member to disconnect from voice.

### `reason`

**Type:** `string`.

Optional audit log reason.
