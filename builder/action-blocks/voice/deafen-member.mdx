The **Deafen or Undeafen** block lives in the **Voice** palette category. Server deafen or undeafen a member.

## What it does

Server deafen or undeafen a member.







## Configuration

Open the block in the builder sidebar to configure these fields.

<ParamField path="action" type="string" required>
  Server deafen state to apply.

Options: `deafen`, `undeafen`, `toggle`.
</ParamField>

<ParamField path="user_id" type="user" required>
  Target member.
</ParamField>

<ParamField path="reason" type="string">
  Optional audit log reason.
</ParamField>
