Moderation actions against members: kick, ban, timeout, nickname changes.

Categories mirror the builder block palette. Search the palette or use the links below to jump to a specific block.

## Blocks

- [Kick or Ban a member](/builder/action-blocks/users/kick-ban) — Remove a member from the server by kick or ban.
- [Timeout a member](/builder/action-blocks/users/timeout) — Apply or remove a Discord timeout.
- [Rename user](/builder/action-blocks/users/rename-user) — Change a member nickname in the server.
- [Leave server](/builder/action-blocks/users/leave-server) — Make the bot leave a server.
