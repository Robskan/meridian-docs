The **Event** block is in the **Event flow** category in the Meridian builder.

Starts when Discord emits this client event or when a webhook hits your bot..

<Note>
  This block is placed automatically by the builder. You cannot add it from the block palette.
</Note>

## Settings

### Friendly name

Shown on the canvas and in your event list.

### Client event

discord.js event name, for example messageCreate.

### Trigger on users / bots / webhooks

Filter which message authors can start the flow.
