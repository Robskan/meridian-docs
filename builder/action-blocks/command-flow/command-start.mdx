The **Command** block is in the **Command flow** category in the Meridian builder.

Starts when someone runs this slash command, prefix command, or context menu action..

<Note>
  This block is placed automatically by the builder. You cannot add it from the block palette.
</Note>

## Settings

### Trigger type

Slash command, prefix command, user context menu, or message context menu.

### Friendly name

Shown on the canvas card and in your command list.

### Discord command name

What users type in Discord. Lowercase, no spaces.

### Discord description

Shown in Discord slash command autocomplete.

### Command name

For prefix commands: the word after your prefix.

### Aliases

Up to 5 alternate prefix names for the same command.

### Test mode

Skips destructive steps so you can try the flow safely.
