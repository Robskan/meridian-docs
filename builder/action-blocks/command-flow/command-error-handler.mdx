The **Error handler** block is in the **Command flow** category in the Meridian builder.

Runs when this command throws or fails..

<Note>
  This block is placed automatically by the builder. You cannot add it from the block palette.
</Note>

## Settings

### Disable error handler

When on, failures skip custom error blocks and only show the built-in flow error card.

### Only show errors to owner or cowork

Hides flow error messages from everyone else in the channel.

### Send errors to Discord webhook

Posts a copy of each flow error to a webhook URL.
