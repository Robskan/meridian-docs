Create and manage channels, forum posts, and hosted transcripts.

Categories mirror the builder block palette. Search the palette or use the links below to jump to a specific block.

## Blocks

- [Create a Channel](/builder/action-blocks/channels/create-channel) — Create a text, voice, category, or thread channel.
- [Create a Forum Post](/builder/action-blocks/channels/create-forum-post) — Create a new post in a forum channel.
- [Edit Forum Post](/builder/action-blocks/channels/edit-forum-post) — Modify settings and tags of an existing forum post.
- [Delete a Channel (incl. Threads)](/builder/action-blocks/channels/delete-channel) — Delete a channel or thread.
- [Edit a Channel (incl. Threads)](/builder/action-blocks/channels/edit-channel) — Modify channel name, topic, or NSFW settings.
- [Create a Transcript](/builder/action-blocks/channels/create-transcript) — Export channel history to a hosted HTML transcript.
