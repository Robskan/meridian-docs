Bot-wide or server-local settings: prefix, presence, profile, and restarts.

Categories mirror the builder block palette. Search the palette or use the links below to jump to a specific block.

## Blocks

- [Set prefix](/builder/action-blocks/settings/set-prefix) — Change the bot command prefix globally or per server.
- [Set status](/builder/action-blocks/settings/set-status) — Change the bot presence, activity, and status text.
- [Change bot profile](/builder/action-blocks/settings/change-bot-server-profile) — Update the bot avatar, banner, username, or server nickname.
- [Restart Bot](/builder/action-blocks/settings/restart-bot) — Restart the bot process to clear memory or resolve hanging.
