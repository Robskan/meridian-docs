The **Edit Forum Post** block lives in the **Channels** palette category. Modify settings and tags of an existing forum post.

## What it does

Updates forum post title, tags, archive state, lock state, and slowmode.



## Configuration

Open the block in the builder sidebar to configure these fields.

### `channel_id`

**Type:** `channel`. Required.

Thread/post to edit.

### `new_name`

**Type:** `string`.

Updated title.

### `applied_tags`

**Type:** `forum-tags`.

Set, add, or remove tags.
