The **Create a Transcript** block is in the **Channels** category in the Meridian builder.

Export channel history to a hosted HTML transcript..

## Settings

### Channel

Current channel, specific id, variable, or a Create Channel block reference.

### Output variable prefix

Creates variables like {vars.ticket_log_url}.

### Protection

Public, role-gated, password, or both.
