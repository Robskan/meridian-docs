The **Delete a Temporary Variable** block lives in the **Variables & Data storage** palette category. Remove a temporary variable from the current run.

## What it does

Remove a temporary variable from the current run.



## Configuration

Open the block in the builder sidebar to configure these fields.

### `var_name`

**Type:** `string`. Required.

Temporary variable to remove from the current run.
