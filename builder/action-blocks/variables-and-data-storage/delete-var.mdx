The **Delete a Variable** block lives in the **Variables & Data storage** palette category. Remove persistent Storage data for a variable.

## What it does

Remove persistent Storage data for a variable.

## Configuration

Open the block in the builder sidebar to configure these fields.

### `var_name`

**Type:** `string`. Required.

Storage variable name as defined in Storage (not `{VAR_…}` syntax).
