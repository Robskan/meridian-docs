Join, move, mute, and manage voice channel state.

Categories mirror the builder block palette. Search the palette or use the links below to jump to a specific block.

## Blocks

- [Join Voice Channel](/builder/action-blocks/voice/join-vc) — Join a specific voice channel.
- [Leave Voice Channel](/builder/action-blocks/voice/leave-vc) — Disconnect the bot from voice.
- [Move a member from VC](/builder/action-blocks/voice/move-vc) — Move a user between voice channels.
- [Kick a member from VC](/builder/action-blocks/voice/kick-vc) — Disconnect a user from voice.
- [Mute or Unmute](/builder/action-blocks/voice/mute-member) — Server mute or unmute a member.
- [Deafen or Undeafen](/builder/action-blocks/voice/deafen-member) — Server deafen or undeafen a member.
- [Set Voice Channel Status](/builder/action-blocks/voice/set-voice-status) — Set the status message shown on a voice channel.
