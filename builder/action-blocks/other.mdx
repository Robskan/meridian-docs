Timing, interaction waits, string utilities, and debug logging.

Categories mirror the builder block palette. Search the palette or use the links below to jump to a specific block.

## Blocks

- [Wait](/builder/action-blocks/other/wait) — Pause execution for a duration in milliseconds.
- [Wait for interaction](/builder/action-blocks/other/wait-for-interaction) — Pause until someone reacts, sends a message, or uses a component.
- [Text Functions](/builder/action-blocks/other/text-functions) — Manipulate strings with operations like uppercase, replace, and split.
- [Send a log](/builder/action-blocks/other/send-log) — Write debug output to your bot logs.
