The **Timeout a member** block lives in the **Users** palette category. Apply or remove a Discord timeout.

## What it does

Apply or remove a Discord timeout.

## Configuration

Open the block in the builder sidebar to configure these fields.

<ParamField path="user_id" type="user" required>
  Member to timeout or untimeout.
</ParamField>

<ParamField path="duration" type="number" required>
  Timeout length in minutes. Set to `0` to remove an existing timeout.
</ParamField>

<ParamField path="reason" type="string">
  Optional audit log reason.
</ParamField>
