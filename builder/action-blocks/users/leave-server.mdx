The **Leave server** block lives in the **Users** palette category. Make the bot leave a server.

## What it does

Make the bot leave a server.

## Configuration

Open the block in the builder sidebar to configure these fields.

### `guild_id`

**Type:** `guild`.

Server to leave. Leave blank to leave the server where the flow is running.
