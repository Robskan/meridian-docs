The **Repeat** block is in the **Loops** category in the Meridian builder.

Repeat a section of your flow while a condition is true or for a fixed number of times..

## Settings

### Type

While a condition is true, or a fixed number of times.

### Condition

Expression evaluated each iteration for while loops.

### Number of times

How many iterations for fixed loops.
