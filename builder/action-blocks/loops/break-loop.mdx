The **Break a Loop** block lives in the **Loops** palette category. Break out of a running loop early.

## What it does

Stops the active **Repeat** or **Repeat for Each** loop immediately and jumps to its **After loop** block. Use only inside a single loop body—not inside nested loops, which the builder does not allow.

## Tips

- Place inside an If branch when you only want to break on certain conditions.
