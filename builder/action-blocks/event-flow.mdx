Entry blocks for Discord client events and inbound webhooks. Use these when the flow should run without a user invoking a command.

Categories mirror the builder block palette. Search the palette or use the links below to jump to a specific block.

## Blocks

- [Event](/builder/action-blocks/event-flow/event-start) — Starts when Discord emits this client event or when a webhook hits your bot.
