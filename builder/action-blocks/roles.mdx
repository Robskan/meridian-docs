Create, edit, assign, and remove server roles.

Categories mirror the builder block palette. Search the palette or use the links below to jump to a specific block.

## Blocks

- [Add Role](/builder/action-blocks/roles/add-role) — Assign a role to a member.
- [Remove Role](/builder/action-blocks/roles/remove-role) — Remove a role from a member.
- [Create a Role](/builder/action-blocks/roles/create-role) — Create a new role in the server.
- [Delete a Role](/builder/action-blocks/roles/delete-role) — Delete an existing role.
- [Edit a Role](/builder/action-blocks/roles/edit-role) — Modify role name, color, hoist, or mentionable settings.
