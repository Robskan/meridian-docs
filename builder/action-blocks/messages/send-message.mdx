The **Send a Message** block is in the **Messages** category in the Meridian builder.

Send a text message, embed, or Components v2 layout to a channel or user..

## Settings

### Edit content

Open the message editor to build text, embeds, buttons, and select menus.

### Action

Send to a channel, direct message a user, or edit an existing message.

### Destination

Current channel/reply or a specific channel.

### Save message id as variable

Store the sent message Discord id for later blocks.
