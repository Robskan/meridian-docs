The **Set prefix** block lives in the **Settings** palette category. Change the bot command prefix globally or per server.

## What it does

Change the bot command prefix globally or per server.

## Configuration

Open the block in the builder sidebar to configure these fields.

<ParamField path="scope" type="string" required>
  Apply prefix globally or only in the current server.

  Options: `server`, `global`.
</ParamField>

<ParamField path="new_prefix" type="string" required>
  Character(s) users type before prefix commands (for example `!` or `?`).
</ParamField>
