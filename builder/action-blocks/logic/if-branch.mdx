The **Branch** block lives in the **Logic** palette category. Outlet for one If / Else if / Else condition. Created automatically.

## What it does

Represents one conditional outlet from an If statement. Created automatically; not available in the palette.

<Note>
  This block is placed automatically by the builder. You cannot add it from the block palette.
</Note>

<Note>
  Each Branch node maps to one row in the If statement sidebar. Rename conditions there, not on the Branch card.
</Note>
