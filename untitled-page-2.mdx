## Notes

<Callout color="#5E5E5E">
  <Icon icon="key-round" />  Indicates that a `Bot API Key` is required, unless <Badge stroke>OPTIONAL</Badge> is provided after the icon.

  <Icon icon="user-lock" />  Indicates that a `OAuth Token` is required, unless <Badge stroke>OPTIONAL</Badge> is provided after the icon.

  <Icon icon="lock-keyhole-open" />  Indicates that no authentication is required whatsoever.
</Callout>

<Callout color="#5E5E5E">
  <sup>1</sup>The Get Status (16.) endpoint requires a `Bot API Key` if the user makes their bot's status private. If a call is made to a bot with a private status without the key, the endpoint will return <Badge color="red" stroke>401 Unauthorized</Badge>.

  <sup>2</sup>The Apply Marketplace Item to Bot (26.) endpoint requires both the `Bot API Key` and `OAuth Token` for security. The user to who the `OAuth Token` provided belongs to needs to have approved the appropriate permissions for this action.
</Callout>
